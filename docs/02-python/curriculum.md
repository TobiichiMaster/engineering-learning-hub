# Phase 01 · 课程计划 v1.0

目标：L1 → L3（通过实际验证），不以阅读或刷完课程判断完成。每周 36 小时参考：主课 28.8h、CS 5.4h、额外工程 1.8h；主课内的实践不重复计算。Java、Spring、Agent、Infra 暂不安排系统课程。

| 单元 | 核心知识 | 独立验收 |

# 第一阶段实践主线

任务管理与批量 API 服务：从 CLI 筛选数据开始，逐渐加入 SQLite、并发请求、超时重试、状态记录、REST API、测试、日志与 Docker。使用模拟 API 和虚构数据，不需要科研资源。

# 学习与验收

每单元：概念 → 代码预测 → 独立编码 → 调试 → 口头解释 → 归档。允许查官方文档；首次独立练习不让 AI 生成核心实现。通过标准：功能正确、边界情况、测试、解释和独立排错。未通过则定向补练。

# CS 穿插

容器对应数组/哈希/复杂度；函数对应栈；并发对应线程调度/锁；网络对应 TCP/HTTP；持久化对应 SQL/事务；部署对应 Linux 内存/端口。数据库需要系统恢复，不能假设已掌握。

# 第一周建议

完成 Unit 01–02 的基础知识及小练习，尽早学习 Traceback 与断点；进度以验收为准，不强制周末完成。官方入口：https://docs.python.org/3/ 。具体 Python 版本在开始时依据本机环境确定。

# 结业标准

从空目录独立完成一个 Python API 项目，可运行、可测试、可部署；能解释核心代码与数据结构、异常、并发策略及安全配置；在无 AI 代写的情况下修复故障。未通过核心验收不进入 Java 正式课程。课程范围与岗位相关性是初步教学建议，未做具体招聘市场调研。
