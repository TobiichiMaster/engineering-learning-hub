# 学习工作流规范 v1.0

创建/更新：2026-11-26。适用 Engineering Learning Hub 全部课程。目标：就业导向、独立编码、调试排错与技术面试。依据[能力基线](https://chatgpt.com/space/page_b45ee1d876008191ab465e60cc7b44ba)、[学习路线](https://chatgpt.com/space/page_1c3df029ef9881918bb7f6acbf4abdff)、[课程设计规范](https://chatgpt.com/space/page_d84feb3dc3008191a46d57b9e70a195a)及[Python 课程](https://chatgpt.com/space/page_6540eb5d120c81918e1bd0e2142029a0)。

# 1. 学习约束

P0：Python、Java、Spring；P1：CS Fundamentals、AI Agent、Engineering；P2：AI Infra。主课顺序 Python → Java → Spring，之后 Agent、Infra 按需；CS 穿插，Engineering 随主课实践。每周36小时及80/15/5为现有路线的参考，不作为强制工时。只在当前主课达到核心验收后启动下一门；允许回顾已学技术。

# 2. 每次学习闭环

| 步骤 | 操作 | 输出 |
|---|---|---|
| 1 开课 | 读取课程、进度、待复习与相关笔记；明确本节目标 | Lesson ID、目标、前置知识 |
| 2 教学 | What/Why/How、最小代码、底层原理、版本边界 | 可理解的讲解 |
| 3 主动回忆 | 不看答案预测输出或解释原理 | 学习者原始回答 |
| 4 独立实践 | 明确输入输出、边界和约束；先独立尝试 | 代码、运行结果或未完成记录 |
| 5 调试与审查 | 读 Traceback、复现、假设、断点、修复、回归 | 问题与验证证据 |
| 6 验收 | 按复习与验收规范区分理解和实践 | 掌握等级、缺口、补练 |
| 7 归档 | 按知识管理规范检查、更新、读回 | 笔记、日志、实验/错题链接 |
| 8 接续 | 更新进度和复习日期，明确下一步 | 下一 Lesson 或补练任务 |

每次只讲适量内容；不为赶进度跳过薄弱基础。优先关联当前知识点的 CS 理论，不额外开启另一门主课。实际时长由用户记录，不从聊天时间推算。

# 3. AI 与独立学习边界

学习模式默认先由用户写核心代码，AI 可解释概念、提供最小示例及分级提示（概念→定位→伪代码→局部示例），不得把练习的完整答案提前作为独立作业。用户明确要求答案时可以讲解，但该题标记为辅助完成，另出同类题验证。允许查官方文档。科研/生产模式可由 Codex 实现需求，但不能计为独立掌握。未经实际运行不得声称测试通过。

# 4. 每周复盘与中断恢复

每周汇总实际投入（如有）、已验收单元、待巩固、独立代码证据、逾期复习与下周主课目标。计划未达标先调整粒度或补练，不机械加课。中断后从最近一次已验证的学习日志、当前进度及待复习表恢复，不凭模型记忆推定进度。

# 5. 快捷指令

| 用户指令 | 执行动作 |
|---|---|
| 继续学习 | 读取云端当前进度，定位下一课或未完成任务 |
| 开始学习 XXX | 检查先修与当前课程，设定本节目标 |
| 给我练习 | 给输入、输出、约束与测试，不预给答案 |
| 给我提示 | 逐级提示，不默认代写 |
| 审查我的代码 | 检查正确性、可维护性、复杂度及测试 |
| 对我进行测试 | 独立答题或实践，记录证据与等级建议 |
| 归档本次学习 | 查重、增量更新笔记与日志、必要时实验错题及进度，读回并返回链接 |
| 开始今日复习 | 读取到期项目，先测试后讲解 |
| 生成学习周报 | 按真实日志汇总，缺失数据注明 |

仅明确要求归档时写入；无法访问页面时提供 Markdown 草稿及未完成操作，不声称已同步。涉及删除、公开分享、覆盖历史或新自动化时另行取得明确授权。

# 6. 工作流验收

首次真实 Lesson 01 验收时检查：开课读取、独立练习、等级证据、笔记与日志归档、进度与复习日期一致、其他设备可读。若未完成练习可归档为进行中，不得虚构成果。Phase 03 规范建设与实际闭环验收分开记录。
