# 复习与验收规范 v1.0

创建/更新：2026-11-26。目标：通过主动回忆、独立编码、调试与工程交付验证就业能力。依据[能力基线](https://chatgpt.com/space/page_b45ee1d876008191ab465e60cc7b44ba)、[知识盲区](https://chatgpt.com/space/page_950cc5dc8b508191b1019c7306c04b9f)及[课程设计规范](https://chatgpt.com/space/page_d84feb3dc3008191a46d57b9e70a195a)。

# 1. 掌握等级与升级证据

| 等级 | 判定条件 |
|---|---|
| NA | 尚无评估证据，不能推断为 L0 |
| L0 | 尚未学习或目前需要重建，保留历史学习经历 |
| L1 Learning | 接触过、能识别部分概念，但需提示或存在关键误解 |
| L2 Understood | 不看答案独立解释机制、边界，并正确预测代表性代码或场景 |
| L3 Practiced | 独立完成代表性实践，通过正常与边界测试，并解释、定位常见问题 |
| L4 Mastered | 在新场景迁移、调试、优化与解释，经过至少一次间隔复测验证 |

初始自评与答题评估不是独立实践证据。阅读、复制、AI 代写或仅运行成功不自动升级。允许查询官方 API 文档，但记录帮助类型（无提示/文档/概念提示/代码提示/AI 代写）。纯理论主题可用独立推导或场景分析代替代码。等级基于证据而非累计时长；复测暴露关键错误时可降级并保留原因。

# 2. Lesson、Unit 与阶段验收

Lesson：主动回忆概念、预测代码、完成适量练习，记录错误与下一步。Unit：核心概念解释、独立实现或分析、边界测试、调试与工程应用；核心要求全部通过才标记已验收，拓展任务可延后。未通过时标记待验收并安排针对性补练。阶段：依据课程大纲结业要求，独立交付可运行、可测试、必要时可部署的项目，并完成项目讲解、代码审查和模拟面试。Python 目标 L3，Java/Spring 仍按各自未来大纲验收。

| 维度 | 建议评分权重 | 验收证据 |
|---|---|---|
| 理论理解 | 30% | 独立解释、机制、边界 |
| 代码能力 | 25% | 独立实现、正确性 |
| 工程实践 | 25% | 测试、配置、交付、选型 |
| 问题解决 | 20% | 复现、定位、修复、回归 |

权重沿用初始评估框架，仅作反馈；单课缺少适用维度时注明 NA，不伪造总分。核心功能、关键概念或安全约束未通过时，即使加权分高也不得通过。

# 3. 间隔复习机制

建议从首次达到 L2 或通过该知识点验收的日期 D 起，安排 D+1、D+3、D+7、D+14、D+30 的复习。该间隔是可调整的初始规则，不代表精确最优。复习先闭卷回忆/做题，再检查答案。通过进入下一间隔；部分通过次日补测，失败回到 D+1 阶段，重新讲解后用变式题确认。L0/L1 的核心缺口先补课，不因日期到期假定已掌握。

复习任务字段：知识点 ID、关联笔记、优先级、上次结果、间隔阶段、到期日期、实际复习日期、证据、下次日期。每天优先处理到期的核心知识和错题；建议从主课与 CS 的原定学习时间内安排短复习，不新增硬性多科并行课程。逾期时从实际完成日期重新安排，不补造历史记录。

# 4. 错题闭环

使用[错题模板](https://chatgpt.com/space/page_93b1793280448191a1759d24c8148794)。记录原题、原答、实际错误、根因（概念/语法/算法/边界/调试/工程）、修复过程、独立验证及知识点 ID。重做应使用相同目标的变式题而非背答案。核心错题至少通过一次独立重做及一次间隔复测才关闭；仍需提示则保持开放。

# 5. 周复盘和阶段总结

每周检查实际学习时长（若提供）、完成的必修单元、独立练习、掌握变化、错题未关闭项及待复习项。优先补齐高频就业核心知识和阻塞先修；不因某周计划未完成就同时开启下一主课。阶段结束更新当前能力档案、知识盲区和下一阶段计划；原基线保留。

# 7. 自动化边界

本规范只定义复习规则，不创建提醒、周报或后台任务。Phase 06 另行授权并验证数据读取、时区、频率及缺失资料处理。没有真实学习证据不更新等级或虚构到期清单。
