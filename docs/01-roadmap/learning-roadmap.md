# 学习路线 v1.2 · 2026-11-26

就业导向；单主线顺序学习：Python → Java → Spring → AI Agent → AI Infra。CS Fundamentals 穿插复习，Engineering 随主课实践。

| 阶段 | 主课 | 优先级 | 验收 |
|---|---|---|---|
| 1 | Python | P0 | 独立开发、测试、部署 Python API 项目 |
| 2 | Java | P0 | 独立 Java 应用，集合、并发、JVM 核心理解 |
| 3 | Spring | P0 | 完整 Java 后端项目 |
| 4 | AI Agent | P1 | 独立实现可部署 Agent |
| 5 | AI Infra | P2 | 模型部署及资源性能分析 |

参考每周 36 小时：当前主课 80%（28.8h），CS 15%（5.4h），额外工程 5%（1.8h）。不安排 Python 和 Java 等主课并行；比例按实际进度调整。
